# 우아한테크코스 BE 8기 프리코스 1주 차 미션: 문자열 덧셈 계산기

## 기능 목록

- [x] 덧셈할 문자열을 입력받는 기능을 구현한다. (입력 안내 문구 출력 포함)
- [x] 입력 문자열이 빈 문자열이거나 null일 경우 0을 반환하는 기능을 구현한다.
- [x] 입력 문자열이 쉼표(,) 또는 콜론(:)을 구분자로 가질 경우, 구분자를 기준으로 분리한 각 숫자의 합을 반환한다. (e.g., "1,2:3")
- [x] 커스텀 구분자를 지원한다.
    - [x] "//"와 "\n" 사이의 문자를 커스텀 구분자로 사용하여 분리한다. (e.g., "//;\n1;2;3")
- [x] 구분자로 분리한 값이 숫자가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 입력된 숫자가 음수일 경우 `IllegalArgumentException`을 발생시킨다. (요구사항의 "양수" 조건 고려)
- [x] 계산된 최종 합계를 "결과 : [합계]" 형식으로 출력한다.
- [x] 사용자가 잘못된 값을 입력할 경우(Exception 발생 시) 애플리케이션이 종료되도록 처리한다.
